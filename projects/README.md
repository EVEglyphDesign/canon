# Project canons

Per-project `NARROWING.md` files land here. Each one:

- Cites [`../NARROWING.md`](../NARROWING.md) for layers 1 (boot contract)
  and 2 (inherited compliance) by section anchor.
- Fills §3 with the project's blueprint.
- Fills §4 with the project's reference framework (SAP Activate, PMI,
  APQC, or a client framework).
- Fills §5 with the project's specific rules.
